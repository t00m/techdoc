# Hello world

First document in the techdoc knowledge base.

## What is this?

This repository is a live demo of KB4IT using the **techdoc** theme. Source files go in `source/`, and the built site is published to `docs/` via GitHub Pages.

## Workflow

- Write Markdown source files in `source/`.
- Push to `main` -- GitHub Actions builds the site automatically.
- Published at the GitHub Pages URL configured for this repository.
